# CloudGovernIQ

CloudGovernIQ provides focused, read-only cloud governance assessments for Microsoft Azure environments.

## Cloud Governance Assessment

The V1 assessment reviews selected areas including:

- Public network exposure
- HTTPS and TLS configuration
- Key Vault protection
- Azure SQL network access
- Cosmos DB network access
- Container Apps ingress
- Required resource tags

Customers receive:

- Governance score
- Prioritized findings
- Resource-level evidence
- Remediation guidance
- PDF assessment report
- 30-minute findings review
